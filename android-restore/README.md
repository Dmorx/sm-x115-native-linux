# بازگردانی بوت اندروید — SM-X115

این بسته شامل `boot.img` و `up_param.bin` اصلیِ ذخیره‌شده از پروژهٔ همین تبلت است. پارتیشن‌های userdata، EFS، NVRAM، حساب‌ها و فایل‌های شخصی داخل آن نیستند. این فایل **رام کامل اندروید نیست** و خرابی system/vendor یا تغییرات سایر پارتیشن‌ها را تعمیر نمی‌کند.

## ساخت فایل قابل استفاده

کل مخزن را دانلود کنید و از داخل آن اجرا کنید:

```sh
python3 android-restore/reassemble.py
```

خروجی `android-restore/SM-X115-restore-android-boot.tar` است. اسکریپت هش همهٔ بخش‌ها، آرشیو و هر دو تصویر را کنترل می‌کند و هیچ دستوری روی تبلت اجرا نمی‌کند. فایل‌های `part` را مستقیم فلش نکنید.

## استفاده

فقط برای مدل SM-X115 و پس از تطبیق با فریمور اصلی دستگاه استفاده شود. نسخهٔ دقیق فریمور این بکاپ برای سازگاری عمومی به‌طور مستقل احراز نشده است؛ یکسان بودن مدل به‌تنهایی تضمین سازگاری نیست. در صورت تردید، فریمور کاملِ مناسب نسخه و بوت‌لودر دستگاه را تهیه کنید.

این tar برای انتخاب در بخش AP ابزار Odin بسته‌بندی شده است؛ فلش همین بستهٔ جدید با Odin تست نشده است. گزینهٔ Re-Partition را فعال نکنید و فایل PIT اضافه نکنید. قبل از فلش، از داده‌های خود نسخهٔ پشتیبان بگیرید. بسته شامل دستور فلش خودکار یا حذف اطلاعات نیست.

در بازگردانی قبلی، هر دو پارتیشن نوشته و با خواندن مجدد و SHA-256 تأیید شدند. اندروید بلافاصله تأیید نشد؛ کاربر بعداً ریست فکتوری انجام داد و سپس لوگوی Samsung و اتصال USB در حالت MTP مشاهده شد. بنابراین حفظ داده‌ها یا بوت بدون ریست تضمین نشده است. ریست فکتوری اطلاعات کاربر را پاک می‌کند و این بسته آن را خودکار انجام نمی‌دهد.

فایل Linux و بکاپ Debian مستقل از این بسته‌اند. این بازیابی فقط بوت اندروید و تصاویر آغازین سامسونگ را برمی‌گرداند.
